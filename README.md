### Hi, I'm Lucas 👋

I like to understand how things work, all the way down. Computer science,
engineering, economics, math, physics: I go broad first, then pick something
and go deep.

Most of that curiosity ends up in two places:

- **Markets & risk.** Hunting for alpha in any market I can model, whatever
  it's based on. I build the scrapers, the data pipelines and the models, and
  keep studying the economics underneath.
- **Building & self-hosting.** I run a homelab with my own services, and I'm
  building tools for everyday problems, like finding deals and saving money.
  With AI, the gap between an idea and a working project has never been
  smaller, so I'm building a lot more.
